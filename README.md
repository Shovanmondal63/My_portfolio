## ✨ Features

- 🎬 **Animated Loader** — Smooth branded intro with progress bar before the site reveals
- 🖊️ **Typewriter Effect** — Cycles through roles: Software Developer, Full-Stack Developer, App Developer, and more
- 🎨 **Glassmorphism UI** — Frosted-glass cards with glowing orbs and depth effects
- 📱 **Fully Responsive** — Works seamlessly across desktop, tablet, and mobile
- ⚡ **Scroll Reveal Animations** — Sections and elements animate into view as you scroll
- 📊 **Animated Skill Bars** — Skill proficiency bars that animate on scroll
- 📂 **Project Slider** — Interactive carousel showcasing projects with tech tags
- 📄 **CV / Resume** — Triggers PDF download and redirects to a dedicated resume page
- 📬 **Contact Form** — Functional form powered by [Web3Forms](https://web3forms.com/) — no backend required
- 🔒 **Content Protection** — Basic right-click and keyboard shortcut protection

## 🚀 Getting Started

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/Shovanmondal63/My_portfolio.git

# 2. Open in your browser — no build step needed
cd My_portfolio
open index.html
```

### Set Up the Contact Form

1. Sign up at [web3forms.com](https://web3forms.com/) to get a free API key.
2. In `index.html`, find the hidden input and replace the placeholder:

```html
<input type="hidden" name="access_key" value="YOUR_WEB3FORMS_KEY_HERE">
```

## 💡 Customisation

| What to change | Where |
|---|---|
| Name, bio, social links | `index.html` — Home & About sections |
| Profile photo | Replace `assets/home.png` |
| Skill levels | `index.html` — `data-level` and `--pct` values in the skills grid |
| Projects | `index.html` — Work section slider cards |
| Resume PDF | Replace `assets/Resume.pdf` |
| Colors & fonts | `style.css` — CSS custom properties at the top |
| Typewriter roles | `script.js` — `roles` array |
